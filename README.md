# Miltron Bank Dashboard

## Project Overview

This Power BI dashboard analyzes customer spending behavior, income utilization, demographic trends, and payment preferences for Miltron Bank customers.

The dashboard provides actionable business insights into customer financial behavior, helping understand spending patterns across cities, genders, occupations, age groups, and spending categories.


## Tools Used

- Power BI
- DAX
- Power Query
- Excel / CSV


## Key KPIs

- Total Customers: 4000
- Income Utilization: 1.19%
- Average Income: 51.66K
- Average Spending: 614.46


## Dashboard Features

### Customer Insights
- Gender-wise spending analysis
- Age group spending comparison
- Occupation-wise average income analysis
- City-wise spending visualization using map charts

### Spending Analysis
- Spending by payment type
- Category-wise spending trends
- Customer spending distribution
- Financial behavior analysis

### Interactive Features
- Dynamic filters and slicers
- KPI Cards
- Interactive visualizations
- Drill-down insights


## Key Insights

- Male customers contributed the majority of total spending.
- Credit Cards were the most preferred payment method.
- Customers aged 25–34 showed the highest spending behavior.
- Salaried IT Employees had the highest average income.
- Bills and Groceries were the highest spending categories.
